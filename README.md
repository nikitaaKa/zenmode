# ZenMode

Минималистичное расширение для браузеров на базе Chromium (Google Chrome, Microsoft Edge, Brave и др.), которое превращает текущее окно в спокойное полноэкранное рабочее пространство с всплывающей панелью навигации и поддержкой ИИ.

---

## Возможности

- **Полноэкранный режим Zen (`Alt+Shift+Z`)**: скрывает интерфейс браузера для максимальной концентрации на контенте. Выход осуществляется повторным нажатием комбинации или клавишей `Escape`.
- **Всплывающая панель управления**: плавно появляется только тогда, когда курсор мыши подводится к верхнему краю экрана.
- **Управление вкладками**:
  - Быстрое переключение между открытыми вкладками с отображением фавиконов сайтов;
  - Закрытие вкладок кнопкой `✕` прямо из панели;
  - Мгновенная синхронизация открытых и закрытых вкладок в реальном времени.
- **Умная адресная строка**:
  - Автоматическое выделение адреса при фокусе;
  - Распознавание доменов (`example.com`), `localhost` с портами, IP-адресов и поисковых запросов.
- **Интерактивные закладки**: проверка статуса страницы и добавление/удаление закладок в один клик (`★` / `☆`).
- **Минималистичная страница новой вкладки**:
  - **Google Search** — стандартный поиск в вебе;
  - **Google Search (AI Mode)** — поиск Google в режиме искусственного интеллекта (`udm=50&aep=11`);
  - **Gemini** — диалог с Google Gemini AI (`gemini.google.com`);
  - Запоминание выбранного режима поиска для последующих вкладок.

---

## Установка

1. Откройте страницу `chrome://extensions` или `edge://extensions`.
2. Включите **Режим разработчика** (Developer mode).
3. Нажмите **Загрузить распакованное расширение** (Load unpacked) и укажите папку `zenmode-main`.
4. Откройте любую страницу и нажмите `Alt+Shift+Z` или кликните по иконке расширения на панели инструментов.

# ZenMode (English)

A calm, distraction-free browser extension for Chromium-based browsers (Chrome, Edge, Brave, etc.) that turns any window into a fullscreen workspace with an on-demand top navigation bar and AI integration.

---

## Features

- **Zen Fullscreen Mode (`Alt+Shift+Z`)**: Hides browser clutter and window frames for deep focus. Exit anytime with `Alt+Shift+Z` or `Escape`.
- **On-Demand Floating Panel**: Smoothly reveals browser controls when the cursor touches the top edge.
- **Tab Management**:
  - Fast switcher across all open tabs displaying real website favicons;
  - Close tabs with a dedicated `✕` button directly from the toolbar;
  - Live synchronization when tabs are opened, closed, or updated.
- **Smart Omnibox**:
  - Auto-selects URL upon focus;
  - Automatically handles domain navigation (`example.com`), localhost ports, IP addresses, and search queries.
- **Interactive Bookmarks**: Live bookmark status check with instant toggle (`★` / `☆`).
- **Clean New Tab Page**:
  - **Google Search** — standard web search;
  - **Google Search (AI Mode)** — Google Search with native AI Mode enabled (`udm=50&aep=11`);
  - **Gemini** — Google Gemini AI interface (`gemini.google.com`);
  - Automatically preserves your selected search mode.

---

## Installation

1. Navigate to `chrome://extensions` or `edge://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked** and choose this `zenmode-main` directory.
4. Open any webpage and press `Alt+Shift+Z` or click the ZenMode icon in the toolbar.
